# Hướng dẫn sử dụng file tài nguyên (Resource Guide)

* **Khi nào sử dụng:** Sử dụng file này khi cần định hướng và lựa chọn kiểu nền (Background Type) cho từng section trên Landing Page để đảm bảo tính mỹ thuật cao và phân định rõ ranh giới trực quan.
* **Cách sử dụng hiệu quả:**
  * Căn cứ lựa chọn: Dựa vào phong cách trực quan (Visual Style) của dự án, mẫu bố cục (Layout Pattern) của section, và quy tắc đổi màu nền liên tiếp giữa các section (Background Alternation) để trang không bị phẳng và đơn điệu.

---

**BACKGROUND TYPES**

| Loại | Đặc điểm | Dùng khi |
|---|---|---|
| Solid Color | Màu đặc, phẳng, không gradient | Section thông thường, tạo sự rõ ràng, tối giản |
| Gradient Linear | Chuyển màu theo đường thẳng (ngang, dọc, chéo) | Hero, CTA, section cần năng lượng và chuyển động |
| Gradient Radial | Chuyển màu từ tâm ra ngoài | Hero section, spotlight effect, tạo điểm nhấn trung tâm |
| Gradient Mesh | Nhiều điểm màu pha trộn tự nhiên, phức tạp | Hero cao cấp, creative/agency, section cần visual mạnh |
| SVG Shape / Blob | Hình dạng hữu cơ bất đối xứng làm decorative | Hero, CTA, section cần điểm nhấn không dùng ảnh |
| Geometric Pattern | Pattern lặp lại từ hình học (grid, dot, line, triangle) | Section cần texture nhẹ, tránh flat design đơn điệu |
| Noise / Grain Texture | Texture hạt mịn phủ lên background | Section cần cảm giác thủ công, ấm áp, cao cấp |
| Image Background | Ảnh thật làm nền, thường có overlay màu bán trong suốt | Hero full-width, section cần cảm xúc mạnh từ hình ảnh |
| Video Background | Video loop làm nền | Hero section sản phẩm/dịch vụ cần demo trực quan |
| Glass / Frosted | Nền mờ trong suốt (backdrop-filter blur) | Card nổi trên ảnh, modal, floating element |
| Dark Overlay | Lớp màu tối phủ lên ảnh/video, thường 40-70% opacity | Khi dùng image background cần đảm bảo text readable |
