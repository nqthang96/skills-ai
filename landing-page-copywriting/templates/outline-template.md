# Landing Page Outline Template

> File này định nghĩa cấu trúc và format chuẩn cho bản Outline Landing Page.
> outline-builder.md phải đọc và tuân theo file này khi xây dựng outline.

---

## Thông Tin Tổng Quan

| Trường | Nội dung |
|---|---|
| Tên dự án / sản phẩm | |
| Loại LP theo mục tiêu | _(vd: Lead Generation / Sales / Webinar Registration...)_ |
| Loại LP theo format | _(vd: Long-form Sales Letter / VSL / Squeeze Page...)_ |
| Awareness Level | _(Unaware / Problem-aware / Solution-aware / Product-aware / Most-aware)_ |
| Traffic source chính | _(vd: Facebook Ads / Google Ads / Email / Organic...)_ |
| Tone of voice | _(vd: Empathetic + Authoritative)_ |
| Copywriting Style | _(vd: Story-driven + Direct Response)_ |
| Chuyên gia tham chiếu | _(nếu có)_ |
| Landing page mẫu | _(nếu có)_ |
| Mục tiêu chuyển đổi | _(hành động cụ thể người dùng cần thực hiện)_ |
