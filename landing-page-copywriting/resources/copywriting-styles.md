# Copywriting Styles Library — Thư viện Phong cách Copywriting

> AI tra file này để xác định Copywriting Style phù hợp.
> Có thể kết hợp nhiều style trong cùng một landing page.

---

| Style | Bản chất | Phù hợp với |
|---|---|---|
| Direct Response | Bán hàng trực diện, đo được | Traffic nóng, offer rõ ràng, Most-aware |
| Educational | Giáo dục trước, bán sau | Sản phẩm mới, Solution-aware, B2B |
| Storytelling | Kể chuyện để tạo kết nối cảm xúc | Traffic lạnh, Problem-aware, lifestyle |
| Authority | Chuyên gia, đáng tin | High-ticket, B2B, sản phẩm cần expertise |
| Conversational | Gần gũi như trò chuyện | B2C, trẻ, social media traffic |
| Premium | Cao cấp, tinh tế, ít chữ | Luxury, sản phẩm premium |
| Data-driven | Dựa trên số liệu và bằng chứng | B2B, SaaS, audience lý trí |
| Emotional | Đánh vào cảm xúc | Wellness, beauty, phát triển cá nhân |
| Challenger | Mạnh, phản biện niềm tin cũ | Thought leader, sản phẩm disruption |
| Minimalist | Ngắn gọn, hiện đại | Tech, startup, Most-aware audience |
| Technical | Rõ tính năng / cách hoạt động | Developer, engineer, technical buyer |
| Transformation | Trước/sau, hành trình thay đổi | Coaching, fitness, khóa học |
| Comparison | So sánh cách cũ / cách mới | SaaS, tool, giải pháp thay thế |

---

## Bảng kết hợp style theo tình huống

| Tình huống | Style chính | Style hỗ trợ |
|---|---|---|
| Traffic lạnh, sản phẩm mới | Storytelling / Emotional | Educational |
| Traffic nóng, có offer | Direct Response | Minimalist |
| Sản phẩm B2B phức tạp | Educational / Data-driven | Authority |
| Sản phẩm premium | Premium / Authority | Minimalist |
| Audience nghi ngờ | Data-driven / Authority | Conversational |
| Coaching / phát triển bản thân | Transformation / Emotional | Storytelling |
| Social media traffic | Conversational / Storytelling | Emotional |
| Disrupt thị trường | Challenger | Storytelling |

---

## Ghi chú áp dụng
- Một landing page thường dùng 2–3 style kết hợp
- Style chính xuyên suốt toàn trang, style phụ xuất hiện ở các section cụ thể
- Không kết hợp mâu thuẫn: ví dụ Premium + Direct Response thường phá vỡ cảm giác cao cấp
